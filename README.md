**Tech Project Manager & Développeur Full Stack** basé à Dakar, Sénégal 🇸🇳

Je pilote des projets digitaux de bout en bout (cadrage, équipe de 5 développeurs, développement, mise en production) tout en gardant les mains dans le code et sur les serveurs. Ce qui me motive : voir une solution grandir et aider ceux qui l'utilisent.

## 🔭 Ce sur quoi je travaille

- **Widan** : un écosystème e-commerce (application mobile Flutter, API NestJS, application web Angular) qui permet aux commerçants en ligne de créer un compte et d'ouvrir leur boutique avec un lien généré. Pensé comme une alternative à Shopify pour l'Afrique, notamment le Sénégal.
- **Burn** : une PWA de suivi d'entraînement (Angular, NestJS, PostgreSQL), en bêta avec environ 50 utilisateurs à Dakar, Lomé et en France.
- **Un chatbot WhatsApp pour restaurants** (NestJS, API de Meta) : consultation du menu, prise de commande et réponses aux questions des clients. En phase de test.
- **Paiements Shopify** : un système de paiement mobile money et carte bancaire multi-marchands basé sur Bictorys, réalisé pour Bold Agence.
